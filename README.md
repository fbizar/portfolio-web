# Mi portalio web personal - fbizar
Sitio web responsive como desarrollador de videojuegos Unity y web.

**Enlace:** [fbizar.github.io/portfolio-web](https://fbizar.github.io/portfolio-web/)

## Páginas
- `index.html`: Sobre mi, tecnologías, proyectos y contacto.

## Tecnologías
- HTML5 semántico
- Tailwind v4 (CLI)

## Framework elegido y justificación
Elegí Tailwind para construir mi portafolio porque me da más margen de personalización como crear también componentes personalizados y es liviano en comparación a bootstrap, ya que el sitio queda con el css que realmente va a utilizar.

## Diseño

### Paleta de colores

|Token|Hex|Uso|
|---|---|---|
|`text`|`#ebf7f3`|Texto general|
|`background`|`#141414`|Fondo de la página|
|`primary`|`#9cf052`|Logo, acciones principales y énfasis|
|`secondary`|`#553b4b`|Separadores y bordes sutiles|
|`accent`|`#eb366b`|Bordes de títulos y detalles destacados|
|`surface`|`#241e22`|Header y tarjetas|
|`surface-muted`|`#382c33`|Etiquetas y botón secundario|

`surface` y `surface-muted` son tonos derivados de `secondary`, oscurecidos para separar las tarjetas del fondo.

### Tipografía

- **Fuente:** [Titillium Web](https://fonts.google.com/specimen/Titillium+Web) (Google Fonts)
- **Pesos:** 200, 300, 400, 600 y 700, con sus cursivas

|Elemento|Clases|
|---|---|
|Título de sección (`h2`)|`text-2xl font-bold`|
|Título de tarjeta (`h3`)|`text-xl font-bold`|
|Texto base|`font-sans` (400)|
|Etiquetas|`text-xs font-semibold`|
